# 업무일지 PWA v8.7.0: 여러 요청 업무 일괄 추가

기준: 업무일지 v8.6.1. APP_VERSION `8.7.0`, 서비스 워커 캐시 `worklog-cache-v8-7-0`, 백엔드 API `schemaVersion 3` (변경 없음).

## 이번 버전 기능

- `요청받음`을 선택하면 `+ 여러 업무 한꺼번에 추가` 버튼이 나타난다. 기존 기본/내가 먼저 함/요청받음 **단건 입력**은 유지한다.
- 일괄 모드에서 업무명을 최대 20행 입력한다. 여러 줄 텍스트를 붙여넣으면 행별로 분리한다. 빈 행은 저장하지 않는다.
- 요청자, 요청 시각, 프로젝트, 메모, 회의/문제해결/협업·지원 태그는 모든 업무에 공통 적용한다. 업무별 예정일은 `개별 예정일 변경`에서 지정할 수 있다.
- 일괄 모드에서는 `지금` 선택을 감추고 `오늘/내일/날짜`만 사용한다. **모든 업무를 개별적인 대기 요청으로만 등록**한다. 실제로 일을 시작할 때 해당 요청 카드의 `시작`을 눌러야 날짜별 작업 기록이 생긴다.
- 동일한 업무명이 여럿이면 자동 병합하지 않고 확인을 요청한다.
- 기존 입력에 내용이 있으면 일괄 모드 첫 번째 업무명으로 옮기고, 일괄 모드를 취소하면 원래 단건 입력명으로 복원한다.
- 일괄 작성본을 `worklog_batch_request_draft`에 임시 보관한다. 새로 입력·변경할 때 갱신하며, 앱 재실행 시 최대 7일 이내 초안을 복원한다. 제출 성공 시 업무 목록, 전송 큐, 초안 종료 표시를 **같은 로컬 트랜잭션**으로 저장한다.
- 개별 ID를 가진 기존 요청(`Log`) 레코드를 사용하며 **서버에 단건 `ADD_LOG`를 GET 쿼리스트링으로 전송**한다. 일괄 등록 전체가 서버에 원자적으로 저장되는 것은 아니다. 서버에서 일부 전송에 실패하면 실패한 전송 건을 로컬 큐에 유지하고 이후 재시도한다.
- 등록 전에 개별 업무의 GET URL 길이를 검사해 지나치게 긴 값이 로컬에만 저장되어 전송 불능이 되는 상황을 예방한다. 사용자의 서버 URL/토큰이 설정돼 있다면 해당 길이를 기준으로 검사한다.

## 변경된 파일

| 파일 | 변경 |
|---|---|
| `index.html` | 일괄 입력 토글·업무별 목록·저장/취소 UI |
| `app.js` | 일괄 입력, 임시 저장, 복원, 공통/개별 예정일, 입력 제한, 로컬 트랜잭션, GET 길이 검증 |
| `style.css` | 일괄 입력 모바일 레이아웃 및 터치 영역 |
| `sw.js` | 캐시 `worklog-cache-v8-7-0`로 갱신 |

`Code.gs`, `manifest.json`은 **이전과 바이트 단위로 동일한 참고 파일**이다. 기존 서버가 정상적인 v8.6.1 Code.gs라면 이번 업데이트를 위해 Apps Script를 다시 배포하거나 `setup()`을 실행할 필요가 없다. ZIP에 담긴 `Code.gs`의 `TOKEN`은 원본 파일의 **예시 자리표시자**이므로 실서버에 그대로 복사하여 덮어쓰면 안 된다.

## 배포 방법

1. 실사용 Google Sheet 사본과 설정 메뉴의 JSON 백업을 저장한다.
2. GitHub Pages에서 `index.html`, `app.js`, `style.css`, `sw.js` **4개 파일을 통째로 교체**한다.
3. 나머지 `manifest.json`, `icons/`, `screenshots/`, 기존 Apps Script 배포 및 `/exec` 주소는 그대로 둔다.
4. 동일 업무일지가 열린 다른 탭/PWA 창을 모두 닫은 뒤 다시 연다. 필요하면 브라우저에서 새로고침한다.
5. 설정 화면에서 앱 `v8.7.0` 표시를 확인한 뒤 `연결 확인` 및 `지금 동기화`를 실행한다. 기존 서버 v8.6.1과 호환된다.
6. 단건 등록 1건, 일괄 등록 2건, 요청별 시작/완료, 다른 기기 동기화, 비행기 모드 저장 후 복귀를 확인한다.

## 출시 전 확인 상태

- Chromium에 실제 HTML/CSS/JS를 주입한 브라우저 자동 검사 16개 통과. 결과는 `v8.7.0_검증_결과.md` 참고.
- 실제 Google Apps Script 웹 앱 / 실사용 Google Sheet 연동, Galaxy PWA의 키보드·뒤로가기·서비스 워커 갱신, 두 **실기기** 간 동기화는 이 환경에서 직접 수행하지 못했으므로 **현장 검증 필요**.
- ZIP에는 아이콘 및 스크린샷이 없다. **기존 GitHub 저장소의 `icons/` 및 `screenshots/`를 삭제하지 않는다.**

이 프로젝트의 지식 파일도 최신 버전으로 교체해줘.
